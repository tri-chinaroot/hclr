# HCLR 实证案例：对话内嵌采集（Pilot）

> 版本：2026-08-12 ｜ 模型环境：DeepSeek v4 flash

## 背景

HCLR方法稿公布后，为获取真实实证数据，设计了**对话内嵌采集**方式：直接把AI助手对话作为任务事件来源。使用者无需额外填表，统计完全自动。

## 方案设计

| 要素 | 定义 |
|---|---|
| 任务事件 | 一个主题会话（从提出需求到成果确认） |
| 模型环境 m | 绑定的大模型（本例：DeepSeek v4 flash）；AI助手为执行/呈现层，不进入m参数 |
| O0 | 助手首轮输出 |
| h | 使用者的介入消息 |
| O1 | 介入后的输出 |
| O（分子） | 任务事件内模型输出Token（或字符）总和，含全部生成轮次 |
| I（分母） | 使用者介入Token（或字符）总和，**不含初始任务描述** |
| HCLR | O / I（输出/介入杠杆率） |
| C1（第一轮确认） | 结果状态：adopt / partial / reject |
| C2（第二轮确认） | 结果状态：approved / rejected / pending |

## 运作流程

1. 每个主题会话结束 → 助手请求C1（使用者一行回答）；
2. P由助手建议、使用者确认；
3. 每10个任务或每周生成汇总报告；
4. 原始记录本地存储（不入公开仓库，保护隐私）。

## 当前快照

```text
任务数: 5
HCLR = ΣO / ΣI = 18275 / 775 = 23.58
分子O（模型输出chars总和）: 18275 | 平均每任务: 3655
分母I（介入chars总和，不含任务描述）: 775 | 平均每任务: 155
结果状态:
  介入后采纳率: 5/5 = 100%
  第二轮确认: 暂无（成果尚未实际使用）
```

> 说明：pilot-003/004/005 的 O/I 来自 Hermes 会话数据库的真实消息统计（O=assistant文本字符总和，I=user介入字符总和、不含初始任务描述）；C1 待使用者确认。

## 意义

- **零负担验证**：使用者仅在会话结束时回答一行C1，P确认也是一句话；
- **真实数据**：O、I、C1均为真实对话记录，非模拟数据；
- **直接回填论文**：数据积累后，论文第6/7章从"验证计划"改写为"初步验证结果"；
- **反事实控制**：同一模型（DeepSeek v4 flash）、统一口径（chars），满足纵向比较条件。
